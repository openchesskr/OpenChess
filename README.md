# OpenChess

체스 오프닝 학습·연습 애플리케이션.

## 버전 기록

### OpenChess v0.0.4 — 2026/7/13

**성능**
"게임 리뷰"(전체 기보 분석) 기능이 여전히 비정상적으로 느려지던 문제를 해결함. v0.0.2에서 분석 전용 병렬 워커 풀을 도입했지만, 그 풀의 첫 자리는 "유휴 상태일 것"이라는 가정 아래 앱 전역에서 공유하는 메인 엔진을 그대로 재사용하고 있었다 — 그런데 집중 학습의 실수 분석처럼 게임 리뷰와 무관하게 같은 엔진 큐에 계속 평가를 밀어넣는 경로가 있어, 이미 보드에 긴 기보나 많은 후보 수가 떠 있던 상태에서 새 게임을 리뷰하면 그 배경 작업 뒤에서 워커 한 자리가 계속 대기해 분석 전체가 느려지고 있었다. 이제 게임 리뷰는 메인 엔진 큐를 전혀 재사용하지 않고 완전히 독립된 전용 워커들로만 풀을 구성해, 다른 화면에서 무슨 작업이 진행 중이든 영향받지 않도록 함.

### OpenChess v0.0.3 — 2026/7/13

**기능**
도감 탭의 오프닝 수 트리를 나침반형(1.e4/1.d4/1.c4/1.Nf3이 각각 동서남북 네 방향으로 뻗어나가는) 레이아웃으로 전면 재설계함. 트리 정중앙에는 회로 칩 장식을 두어 네 갈래가 여기서 뻗어나간다는 느낌을 주고, 칭호 탭에 있는 13개 대표 오프닝(Italian Game, Ruy Lopez, Scotch Game, Sicilian Defense, Caro-Kann Defense, French Defense, Vienna Game, King's Gambit, Benoni Defense, Catalan Opening, Grünfeld Defense, London System, Queen's Gambit)만 점선 테두리로 하나의 영역으로 묶어 표시함. 영역 안의 더 구체적인 하위 바리에이션은 새 영역을 만들지 않고 그대로 상위 오프닝 영역에 포함되며, 영역 이름은 바깥 여백에 화살표와 장식체 글씨로 표기해 블록과 겹치지 않게 함.

**안정성**
트리가 배경에서 계속 자라는(비동기 로딩) 동안 이미 그려진 블록들이 계속 흔들리거나 위치가 튀던 문제를 근본적으로 해결함 — 형제 순서·leaf 좌표·나침반 팔의 기준점·자식이 있는(internal) 노드의 위치를 한 번 계산되면 다시 바뀌지 않도록 모두 캐싱하고, 위치가 바뀔 때 걸려 있던 짧은 슬라이드 애니메이션을 제거해(반복되는 미세 재조정이 애니메이션과 겹치며 화면이 계속 미끄러지는 것처럼 보였음) 순간 이동하도록 바꿈. 트리 로딩 초반 잠깐(약 3.2초) 재배치가 몰리는 구간은 화면을 가려 사용자가 그 과정을 보지 않게 하고, 화면을 드래그·확대할 때 렉이 걸리던 문제는 우선순위 계산용 Map을 pan/zoom이 바뀔 때마다 다시 만들던 것을 고쳐 해결함. 칭호 점선 영역이 배경 로딩으로 계속 커지다 일정 크기를 넘으면 사라지던 문제도 크기 상한을 없애 해결함.

**UI**
수 블록을 클릭하면 열리는 수 설명 카드가 모식도의 확대/축소 트랜스폼 안에 함께 있어, 축소하면 카드가 화면 밖으로 잘리고 확대하면 카드도 같이 커지던 문제를 해결함 — 카드를 트랜스폼 바깥(화면 좌표계)으로 분리해, 카드 자신의 크기는 항상 모식도 창 크기에 비례한 값으로 고정하고 앵커(수 블록)의 화면상 위치만 pan/zoom을 반영해 따라가도록 함.

### OpenChess v0.0.2 — 2026/7/12

**성능**
특정 대국의 "게임 리뷰"(전체 기보 분석) 기능이 기보가 길어질수록 끝없이 느려지다 멈춘 것처럼 보이던 문제를 해결함. 원인은 워커 하나가 모든 포지션을 순서대로 평가하던 구조라 총 분석 시간이 포지션 수에 정비례해 늘어난 것으로, depth·탐색 시간은 그대로 둔 채(정확도 손실 없이) 같은 엔진 프로필의 워커를 여러 개(Stockfish 18 Lite 4개, Stockfish 16 Full 2개) 띄워 포지션들을 나눠 동시에 계산하도록 바꿈. 이어서 교차 출처 격리(Cross-Origin-Opener/Embedder Policy) 헤더를 배포 설정(Vercel)과 로컬 개발 서버에 추가해 SharedArrayBuffer 기반 멀티스레드 Stockfish를 활성화, 실시간(집중 학습 등) 평가에 쓰는 메인 엔진이 활성 포지션 하나를 여러 CPU 코어로 동시에 탐색하도록 함(교차 출처 격리가 안 되는 구형 브라우저 등에서는 자동으로 기존 단일 스레드 빌드로 폴백). COEP는 require-corp 대신 credentialless를 적용해, CORP 헤더가 없는 외부 이미지(구글 프로필 사진 등) 로딩이 깨지는 부작용을 피함.

### OpenChess v0.0.1 — 2026/7/11

**UI**
모바일에서 상단 UI가 잘리는 문제를 해결하고 상단 UI를 최적화함. 학습 탭과 퍼즐 탭을 제외한 탭에서는 마스코트 이미지를 모두 제거해 UI를 정리하고, 로그인 창에는 마스코트 대신 OpenChess 로고를 표시함. 프로필과 집중 학습 모드에 나오는 모든 대국에 타임 컨트롤(래피드/블리츠/불릿)을 표기하고, 레이팅 증감폭은 게임 결과 뒤 소괄호로 표기함. 마스터 대국이 표시되지 않던 문제를 해결하고(불러오는 중에는 "마스터 대국 기록 탐색 중..."으로 표기), 학습 탭 메인 체스보드 크기를 키우고, 수 체계 아이콘이 계산되기 전에는 3-dot 타이핑 인디케이터 스타일의 바운스 애니메이션을 보여주도록 함. 평가치에 따라 제안 화살표의 두께·투명도가 달라지던 UI가 적용되지 않던 문제를 고치고, 기본 보드 스킨 테두리에 금색 광택 효과를 적용해 사이트 전체 미니 체스보드에도 반영, 기물을 하단 블록 기준으로 정렬하도록 좌표 정렬 문제를 해결함. 도감 탭에서는 수 블록 주변에 오프닝 이름을 표시하고 채택률 대신 책 아이콘을 좌상단에 배치, 퍼즐 탭에서는 퍼즐 블록이 하단 탭에 가리던 문제와 모바일에서 추천 퍼즐이 안 뜨던 문제를 해결하고 모식도 크기를 75%에서 100%로, 2페이지에도 미니 체스보드를 추가해 블록 클릭 시 애니메이션 재생이 되도록 함. 상점 탭은 보유 코인 UI를 축소해 우상단에 배치하고 기물 스킨은 "흑 나이트" 한 기물만, 보드 스킨은 8×8 이미지로 보여주도록 하고, 설정 탭은 내 프로필에 칭호를 이름 위에, 레이팅 변동·정확도를 집중 학습 모드와 통일해 표기함. 친구 기능은 채팅 버튼을 아이콘으로 바꾸고, 친구 삭제 버튼은 프로필 클릭 후 우상단에만 노출되도록 함.

**UX**
집중 학습 모드에서 자주 둔 다음 수를 클릭하면 그 수의 집중 학습 모드로 바로 이동하고, 다른 수의 집중 학습 모드를 거쳐 나갈 때는 체스보드에 해당 수순이 표시되도록 개선함. 도감 탭의 오프닝 수 트리는 첫 위치를 1.e4로 정렬하고 하위 라인을 계속 생성하도록 하며, 수 설명 창이 X 버튼으로 안 닫히던 문제와 오프닝 이름 클릭 시 집중 학습 모드로 이동하지 않던 문제를 해결함. 검색 기능은 버튼을 누르지 않아도 입력값에 따라 실시간으로 프로필을 띄우도록 하고, 프로필 클릭 시 하단 정보 확인이 막히던 스크롤 문제를 해결함. chess.com 연동 시 데이터가 많은 계정의 로딩이 느리던 문제를 보완하기 위해 정보를 순차적으로 불러오는 즉시 표기하고, 최근 대국 기록도 최신순으로 불러오도록 함.

**시스템**
framer-motion 의존성을 추가해 로그인/회원가입 모달에 배경 페이드 및 스프링 인 패널 애니메이션을 적용했고, Claude Code용 ui-ux-pro-max 디자인 스킬을 벤더링해 이후 작업에서 디자인 스타일·색상·타이포그래피·UX 가이드라인을 참고할 수 있게 함.

### OpenChess v0.0.0 (Beta) — 2026/7/10

**기능**
기초적인 웹사이트의 구조와 틀은 모두 갖추었고, 웹사이트의 핵심 기능인 학습 탭과 퍼즐 탭은 거의 완성 단계에 도달, 퀘스트 탭과 도감 탭은 전반적인 수정이 필요하고, 상점 탭 및 설정 탭은 미완성 상태, 그 외 검색 기능, 친구 기능, 채팅 기능, 알림 기능 역시 조금 발전이 필요함. 향후 베타테스팅을 고려하여 개발자 기능의 편의성을 조금 개선할 것.

**UI**
학습 탭을 제외하면 심각한 상태, 여전히 필요없는 텍스트가 너무 많고, 비율이 왜곡되거나 레이아웃이 부자연스러운 부분이 꽤 있으며, 모바일 비율에서는 심각한 불편함을 느낄 정도로 레이아웃이 컷오프되는 현상도 발생함.

**UX**
UI에 비해 비교적 양호한 편이기는 하나 여전히 만족스러울 정도로 부드럽고 깔끔한 느낌은 아님, 특히 웹사이트 전반에 사용되는 체스보드의 착수 UX와 기물 움직임 애니메이션을 가장 먼저 다듬어두면 앞으로 유용할 것으로 보임.

**시스템**
개발 언어는 JavaScript, 전반적인 개발 과정은 Claude Code의 Sonnet 5.0, Opus 4.8, Fable 5로 진행됨, 디자인은 Flaticon, Google Fonts를 활용하였고, 일부 이미지는 직접 디자인함. openchess.kr 도메인과 함께 각 탭을 하나의 경로(/learn, /book, /puzzle, /quest, /store, /setting)로 지정하여 구분하였고, 1차적인 취약점 검사를 통해 일반적인 보안 기준을 충족함. Github Repository에서 개발한 PR을 Merge하면 Vercel에서 자동으로 deploy하는 방식, Supabase를 통해 서버 데이터를 저장하고, OpenChess 자체 계정과 Google OAuth 서비스를 통한 Google 계정을 연동할 수 있게 함.
